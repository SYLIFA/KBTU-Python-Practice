# TSIS 4: Advanced Snake Game
Проект "Змейка" с продвинутыми механиками и базой данных.

## Выполненные требования:
- **База данных:** SQLite3 (таблицы для юзеров и рекордов, использование JOIN).
- **Уровни:** Автоматическое повышение сложности и появление препятствий.
- **Бонусы:** Временная еда (исчезает через 8 секунд, реализовано через `pygame.time.get_ticks()`).
- **Конфигурация:** Настройки хранятся во внешнем `settings.json`.

## Как запустить:
1. Установите pygame: `pip install pygame`
2. Запустите: `python main.py`
